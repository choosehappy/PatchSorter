# PatchSorter
PatchSorter is an open-source digital pathology tool for histologic object labeling. Please see the [documentation](https://patchsorter.readthedocs.io/en/stable/index.html) for installation and usage instructions.

## Contributing
Contributions are welcome! Feel free to fork the repository, make improvements, and submit pull requests.
