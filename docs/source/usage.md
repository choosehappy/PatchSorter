# Usage
We provide a step-by-step user manual here.

## 1. Running PatchSorter
```{note}
If you followed the "quick start" or "multi-node deployment" installation guides, the PatchSorter server and user interface are already running in the background.
```

After installation, open a terminal session within the PatchSorter docker container and run the following command to start the patchsorter server:
```bash
patchsorter server
```

In a second terminal session, run the PatchSorter user interface:
```bash
patchsorter ui
```
