# Welcome to PatchSorter's Documentation!
PatchSorter is an open-source digital pathology tool for histologic object labeling. This documentation provides comprehensive guides on installation, usage, and development of PatchSorter. 

## Contributing
Contributions are welcome! Feel free to fork the repository, make improvements, and submit pull requests.
